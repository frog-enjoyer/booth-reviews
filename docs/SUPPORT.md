# Booth Reviews Support

Use this page for browser-store support, privacy requests, moderation questions, and bug reports for the Booth Reviews browser extension.

## Contact Options

- Public bug reports and feature requests: https://github.com/frog-enjoyer/booth-reviews/issues
- Privacy requests: open a GitHub issue and include `privacy` in the title if the request does not contain private information.
- Security reports: open a GitHub issue and include `security` in the title only if the report does not contain secrets, tokens, exploit details, or private account information.

Do not post Discord tokens, session tokens, private Booth account information, exploit details, or other secrets in public issues.

## Support Scope

Support covers extension installation problems, Booth page compatibility issues, login problems, review submission issues, moderation questions, privacy requests, and browser-store questions.

Booth Reviews is an independent community extension and is not affiliated with Booth.pm, Pixiv Inc., Discord, or VRChat. For Booth account, purchase, download, refund, or seller support, contact Booth directly.

## Response Expectations

This is a small community project, so response times may vary. Clear bug reports with reproduction details are the easiest to investigate.

## Useful Details To Include

- Browser name and version.
- Extension version.
- Booth page URL where the issue happened.
- What you expected to happen.
- What actually happened.
- Screenshots or console errors, if available.
- Whether the issue still happens after disabling other Booth-related extensions.

## Abuse Or Moderation Reports

Use the in-extension report action on the relevant review when possible. If the extension report flow is unavailable, open a GitHub issue with the Booth item URL and a short explanation.

Moderation reports should identify the review or Booth item involved and explain the issue. Do not include private user information unless it is necessary to understand the report.
